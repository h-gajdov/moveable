# REST API

Interactive documentation (OpenAPI 3, generated by springdoc): **`/api/docs`**.
The JSON schema is at `/api/openapi`. All errors are RFC 9457 problem documents
with a stable `code` (e.g. `VALIDATION_FAILED`, `RATE_LIMITED`,
`ORIGIN_OUTSIDE_REGION`). They never contain stack traces or internals.

| Method & path | Purpose |
|---|---|
| `POST /api/routes` | Accessibility-aware routes. Body: `origin{lat,lon}`, `destination{lat,lon}`, `profile`, optional `preferences`, `alternatives`. |
| `GET /api/routing-profiles` | Profiles with default preferences + description of every setting. |
| `GET /api/places?q=` | Self-hosted search (streets, POIs, addresses). Cyrillic and Latin both match. |
| `GET /api/places/reverse?lat=&lon=` | Nearest named path within 60 m. |
| `GET /api/obstacles?bbox=minLon,minLat,maxLon,maxLat` | Verified and pending reports (pending ones are flagged and have no free text or photo). |
| `POST /api/obstacles/reports` | Submit a report (JSON, or multipart with `report` JSON part + optional `photo`). Rate-limited. |
| `POST /api/obstacles/{id}/confirm` | "Still there" confirmation. |
| `GET /api/obstacles/{id}/photo` | Photo of a verified report. |
| `GET /api/coverage?bbox=&grid=true` | Data completeness summary and an optional GeoJSON grid. |
| `GET /api/map-features?bbox=` | Mapped stairs, crossings, kerbs, barriers and benches as GeoJSON (small areas). |
| `GET /api/config` | Region, report categories, attribution. |
| `GET /api/health` | Database and graph status. |
| `GET /api/admin/me` | Admin: current user. HTTP Basic, roles ADMIN/MODERATOR. |
| `GET /api/admin/reports?status=PENDING` | Admin: review queue. |
| `GET /api/admin/reports/{id}` | Admin: report and its status history. |
| `POST /api/admin/reports/{id}/status` | Admin: `{status, note?, extendDays?}`. Transitions are validated. |
| `GET /api/admin/reports/{id}/photo` | Admin: any report photo. |
| `GET /api/admin/ingestion-runs` | Admin: import history and statistics. |

## Route response essentials

```jsonc
{
  "profile": "WHEELCHAIR",
  "preferences": { /* effective preferences after merging */ },
  "origin": { "lat": 41.9961, "lon": 21.4315, "snapDistanceM": 9.7, ... },
  "routes": [{
    "id": "r1",
    "kinds": ["RECOMMENDED", "BEST_COVERAGE"],      // merged when routes overlap ≥85 %
    "distanceM": 941.1, "durationS": 941,
    "geometry": { "type": "LineString", "coordinates": [[lon, lat], ...] },  // mapped network only
    "instructions": [{ "type": "TURN", "modifier": "LEFT", "distanceM": 80, "names": {...},
                       "crossing": { "type": "SIGNALS", "signals": true, "sound": null }, "notes": [] }],
    "summary": { "stairs": 0, "crossings": 2, "raisedKerbs": 0, "unknownSurfaceM": 120, ... },
    "coverage": { "score": 0.47, "level": "PARTIAL", ... },
    "suitability": { "level": "PARTLY_UNKNOWN", "indicators": [{ "need": "KERBS", "status": "UNKNOWN" }] },
    "warnings": [{ "code": "ROUGH_SURFACE", "severity": "WARNING", "lengthM": 60, "location": [lon, lat] }],
    "obstacles": [{ "status": "PENDING", "affectsRouting": false, ... }],
    "explanation": { "reasons": ["REQUIREMENT_NO_STAIRS", "AVOIDS_STAIRS"], "extraDistanceM": 163,
                     "avoidedComparedToShortest": { "stairs": 1, "roughSurfaceM": 145 } }
  }],
  "noRoute": null,          // or { reason, blockingFeatures[], shortestUnconstrainedM }
  "dataNotice": { "code": "ROUTE_NOT_GUARANTEED", "osmDataTimestamp": "..." }
}
```

`null` in any attribute means **not mapped**.
